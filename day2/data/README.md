# Day 2 sample data

## ⚠️ Read this first

`palawan_training_polygons.geojson` and `palawan_validation_polygons.geojson` are **synthetic demonstration
files**. They were generated by `generate_training_data.py`, which places 0.02° squares at *random* locations
inside broad regions of Palawan and assigns each square a class label **without checking the land cover on
the ground or in imagery**. Many polygons therefore fall in the sea or on the wrong land cover.

Use them only to practise file handling (loading GeoJSON into Earth Engine or GeoPandas, styling by class,
counting features). **Do not use them to train or validate a classifier.**

The Day 2 notebooks do not use these files. They derive reference labels directly in Earth Engine:

- Session 1 lab: ESA WorldCover 2021 (5 classes)
- Session 2 lab: ESA WorldCover 2021 + Hansen Global Forest Change (8 classes, proxy labels)

For real projects, collect reference data by photo-interpretation of very-high-resolution imagery or by field
survey, following a documented sampling design (see Olofsson et al., 2014).

## Files

| File | Content |
|------|---------|
| `palawan_training_polygons.geojson` | 80 synthetic squares (10 per class), EPSG:4326; attributes `class_id`, `class_name`, `region`, `type`, `polygon_id` |
| `palawan_validation_polygons.geojson` | 40 synthetic squares (5 per class), same attributes |
| `dataset_summary.json` | Counts per class |
| `generate_training_data.py` | Script that generated the two GeoJSON files (random seed 42) |
| `class_definitions.md` | The 8-class Palawan legend used in Session 2, with spectral characteristics |

## Land cover classification scheme (Session 2)

| ID | Class Name | Description |
|----|------------|-------------|
| 1 | Primary Forest | Dense, mature forest canopy |
| 2 | Secondary Forest | Regenerating forest, lower canopy |
| 3 | Mangroves | Coastal mangrove forests |
| 4 | Agricultural Land | Rice paddies, coconut plantations |
| 5 | Grassland/Scrubland | Open grasslands, sparse vegetation |
| 6 | Water Bodies | Rivers, lakes, coastal waters |
| 7 | Urban/Built-up | Settlements, roads, infrastructure |
| 8 | Bare Soil/Mining | Exposed soil, mining areas |

The synthetic squares cover a box of 117.5–120.5°E, 8.5–11.5°N.

## Loading the files (file-handling practice)

```python
import ee
import geemap

ee.Initialize(project="your-cloud-project-id")   # a Cloud project registered for Earth Engine

fc = geemap.geojson_to_ee("palawan_training_polygons.geojson")
print(fc.aggregate_histogram("class_id").getInfo())

Map = geemap.Map(center=[10.0, 118.9], zoom=7)
Map.addLayer(fc, {"color": "red"}, "Synthetic polygons")
Map
```
